ログイン

Cognito Hosted UI にリダイレクトして認証を行います。
Authorization Code + PKCE フローを使用します。

PKCE フローの流れ

1. code_verifier（ランダム文字列）を生成
2. code_challenge = SHA-256(code_verifier) を計算
3. Cognito /authorize に code_challenge を送信
4. 認証後、Cognito が認可コード（code）を返却
5. code + code_verifier をバックエンドに送信
6. バックエンドが Cognito でトークンに交換
